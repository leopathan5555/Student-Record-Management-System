# Student Record Management System

A desktop GUI application built with **JavaFX** and Object-Oriented Programming (OOP) principles to manage student records through an interactive interface.

## Features
- Add, view, update, delete, and search student records
- Real-time updates via a dynamic TableView
- Search by Name, ID, or Department
- Data persistence using CSV file storage

## Tech Stack
- Java
- JavaFX
- CSV file handling for data storage
